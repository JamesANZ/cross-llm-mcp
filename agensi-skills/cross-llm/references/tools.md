# Cross-LLM tools

| Tool | Use it for |
| --- | --- |
| `call-chatgpt` | OpenAI |
| `call-claude` | Anthropic |
| `call-deepseek` | DeepSeek |
| `call-gemini` | Google Gemini |
| `call-grok` | xAI Grok |
| `call-kimi` | Moonshot Kimi |
| `call-perplexity` | Perplexity |
| `call-mistral` | Mistral |
| `call-huggingface` | Hugging Face Inference Router |
| `call-llm` | One provider by name |
| `call-all-llms` | Every configured provider. Only when the user asks for all of them. |
| `get-models-by-tag` | Models tagged coding, business, reasoning, math, creative, or general |
| `get-model-registry-info` | Registry timestamp and model list |
| `get-user-preferences` | Default model and cost preference |
| `set-user-preferences` | Change those preferences when the user asks |
| `submit-llm-request-async` | Start a job and return its id |
| `get-async-job-result` | Poll one job |
| `list-async-jobs` | List jobs |
| `cancel-async-job` | Cancel a pending or running job |
| `get-prompt-history` | Prompts already sent |
| `get-prompt-stats` | Counts and token totals |
| `delete-prompt-entries` | Delete matching log rows, only when asked |
| `clear-prompt-history` | Delete the whole log, only when asked |
